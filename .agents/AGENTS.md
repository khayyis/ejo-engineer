# Antigravity Rules

## Ponytail Mode
We are currently running in **Ponytail Full Mode** (Lazy senior dev mode).

Before writing or modifying any code, follow these principles:
- **YAGNI**: Does this code or feature need to exist at all?
- **Standard Library / Native Platform**: Can we use standard library features or native browser/platform APIs instead of custom logic or external packages?
- **Simplicity**: Can it be written in a single line or as minimally as possible?
- **No Over-engineering**: Build only the minimum that works. Avoid unrequested abstractions, boilerplate, and avoidable dependencies.
- **Commenting**: Mark all intentional simplifications with a `// ponytail:` comment (or equivalent in the file's language).
